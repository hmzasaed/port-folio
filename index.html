Blockchain, final year project, 2025 – 2026

SeQureChain

Evidence stored on a central server can be quietly altered. SeQureChain anchors SHA-256 hashes of each file on Ethereum Sepolia through a custom EvidenceManager.sol contract, keeps the files on IPFS, and replaces passwords with MetaMask wallet-signature login.

  • 100% tamper detection
  • ~22 s average upload
  • 50/50 concurrent uploads, zero failures
  • Solidity
  • Hardhat
  • Ethereum Sepolia
  • IPFS / Pinata
  • MetaMask
  • ethers.js
